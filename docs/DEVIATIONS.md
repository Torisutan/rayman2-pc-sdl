# Deviations from the original engine structure

Every place where this fork departs from the original module split, names, file layout or data
structures. Each entry gives the place, the change, and why there was no other way.

| # | Where | Change | Why |
|---|---|---|---|
| 1 | `GAM/GAM_init.c` (`FUN_00405a30`), `GAM/pc_winmain.c` (`GAM_pc_fn_WinMain`), `GLI/Init_Gli_helpers.c` (`GLI_pc_fn_vRead/WriteIniString`); `RAYMAN2_LOCAL_UBIINI` | `ubi.ini` is read and written in the working directory (the game folder) instead of the Windows directory (`<windir>\Ubi.ini`, `<windir>\UbiSoft\ubi.ini`). | Current installs ship `ubi.ini` beside the exe and the Windows directory is not writable; without it the graphics DLL is not found. Interim: Phase 2 moves it to a per-user location. |
| 2 | `MMG/MMG_init.c` (`MMG_fn_vInit`, CD drive search `FUN_00448e30`); `RAYMAN2_NO_PROTECTION` | No CD drive search: `g_cCDROM = '.'`, so the engine's CD fallback paths resolve against the working directory. | Copy protection (CD check). |
| 3 | `MMG/MMG_init.c`, `MMG/SNA.c` (`SNA_pc_vInitStream`, `SNA_pc_bOpenFile`, `SNA_pc_bCloseFile`, `SNA_pc_ulSeek`, `SNA_pc_bRawRead*Stubbed`), `MMG/SNA_reloc.c` (`SNA_pc_fn_bReadFile`, `SNA_pc_fn_hCreateFileA`, `SNA_pc_fn_dwSetFilePointer`); `RAYMAN2_NO_PROTECTION` | No private import resolver, LCG code pool or 15-byte call stubs: the file layer calls `CreateFileA`/`ReadFile`/`SetFilePointer`/`CloseHandle` directly; stream flag bit 2 selects the plain readers. The LCG is not seeded. | Copy protection (import hiding). The resolver's memory scan for kernel32 never ends on a 64-bit OS. |
| 4 | `MMG/SNA_reloc.c` (`SNA_pc_vVerifyCdLevelsFile`, `SNA_pc_bOpenEmbeddedSna`, `SNA_pc_fn_hOpenFileAtSinusOffset`, tail of `SNA_pc_vLoadAndRelocate`), `GAM/GAM_engine.c` (`GAM_fn_vChooseTheGoodInit`, `gam_fix_rekey_reloc_table`), `GAM/GAM_levelload.c` (`gam_drm_rekey_reloc_table`, `GAM_pc_fn_vReseedLoadTables`), `GAM/Always.c`; `RAYMAN2_NO_PROTECTION` | Level relocation tables are still decoded from `LEVELS0.DAT` (the data format requires it), always from the first copy (load key byte 2 = 0), from `LEVELS0.DAT` only (not the CD's 24-file split), without decoy table reads, without recording table keys/states and without the checksum bit-flip. | Copy protection (random copy selection, decoys, state the protection actors check). Measured: same level state as the random copies. |
| 5 | `GAM/GAM_levelload.c` (`GAM_pc_fn_vProtectFlaggedObjects`), `MMG/pc_protect.c` (whole tamper block), `AI/Function.c` (`fn_p_ExecuteVariable`); `RAYMAN2_NO_PROTECTION` | No x86 code from level data (DsgVar arrays) is decrypted or executed; `fn_p_ExecuteVariable` skips its arguments and yields 0. | Copy protection (tamper block). Executing level-data code cannot work on any other target. |
| 6 | `GAM/GAM_GameEng.c` (`fn_vMakeCharacterReact`), `AI/Function.c` (`AI_pc_fn_vSetProtectionActor`, `fn_p_stComputeProtectKey`, `fn_p_stComputeXor`, `AI_pc_fn_p_stComputeNotU`), `AI/Procedure.c` (`fn_p_stMiscProtectProcedure`); `RAYMAN2_NO_PROTECTION` | Actors with `GAM_C_CustBitProtection` do not think. The AI functions of the PC protection block set that bit on their caller and read no code image (`MATH_MemoryValue` yields 0, `ACT_UpdateChecksum` changes nothing). | Copy protection (script-side checks that show "CD MISSING"). Their checks compare against the original code image, which a rebuilt engine cannot match. Side effect: these actors no longer draw from the shared random generator (`rnd.index` differs from the original from Morb_00 frame 708; no other hashed field differs). |
| 7 | `GLI/AdjustCamera.c` (`GLI_xAdjustCameraToViewport2`), new `GLI/GLI_ratio.c`; `RAYMAN2_WIDESCREEN` | Perspective cameras without distortion divide tan(xAlphaX / 2) by the viewport's ratio to 4:3 (Hor+); the adjust also records the screen ratio for the 2D paths. The camera's stored angles stay 4:3. | Wide display modes. The original callers pass 4:3 (`1.5f, 0.75f`) and the camera AI rewrites `xAlphaX` from the focal, so the widening cannot live in the callers. Formula as in Ray2Fix (MIT). |
| 8 | `GLI/Object.c` (`GLI_vDraw2DSpriteWithPercent`), `GLI/u_Draw.c` (`GLI_vDraw2DSprite`), `GLI/Texture.c` (`GLI_pc_fn_vWrite16bBitmapToBackBuffer`); `RAYMAN2_WIDESCREEN` | Percent and pixel sprites are mapped into the centred 4:3 band, except sprites spanning the full width (backgrounds, fades). The loading vignette is squeezed into the 4:3 band of its own 640x480 bitmap (columns picked, black sides) before it goes to the driver. | Wide display modes: the original 2D is laid out for 4:3 and stretched. The vignette is squeezed in the bitmap because the renderer DLL in use scales the source by the rect's right edge / 640, so a narrower or wider rect or source does not survive the driver. Full-width test as in Ray2Fix (MIT). |
| 9 | `GLI/Proj.c` (`GLI_vGet3DVertexFromScreenPos`), `AI/AI_globals.h` (`AI_TA_dwScreenWidth`); `RAYMAN2_WIDESCREEN` | Screen positions of superimposed objects are mapped into the 4:3 band, and their scale (fix viewport width / 640, procedures 409/410 and `fn_p_stCode4TextAffiche`) uses the band's width. | Wide display modes: HUD, menu cursor and menu objects are placed and scaled for 4:3. With the Hor+ fix camera (row 7) they keep their proportions; these two keep their place and size. |
| 10 | `GLI/Texture.c` (`GLI_AddToProgressBar`), new `GLI/GLI_fastload.c`; `RAYMAN2_FAST_LOADING` | The progress step calls `GLI_pc_fn_vRefreshProgressUiIfDue` instead of `GLI_RefreshUiSurfaceIfVisible`: the screen refresh (vignette copy and synchronised flip) runs at most once per 100 ms; the bar is still drawn into its buffer at every step. | Each refresh waits for a synchronised flip; together they took more than half of a level load. Measured in PLAN "Loading screen". |
| 11 | `AGO/AGO.c` (`AGO_vDisplayGAUGES`, `AGO_vDisplayIcones`, `JFFTXT_vAffiche`), `GLI/GLI_ratio.c` (`GLI_fn_vSetSafeAreaAnchor`, `GLI_fn_xToSafeArea`); `RAYMAN2_WIDESCREEN` | While the engine is not frozen (the original's own test for the in-game HUD; the pause menu freezes it), a gauge, icon or text string that lies entirely in the left or right third of the 4:3 layout keeps its 4:3 distance to that screen edge instead of being placed in the centred band. Everything else stays in the band (row 8). | Wide display modes: the HUD (health bar, lum and cage counters) belongs at the screen corners, not at the corners of the 4:3 band. The HUD and the menus share the same gauge, icon and text tables, so the frozen flag and the element's own extent decide. |
| 12 | `GAM/pc_winmain.c` (window class registration); `RAYMAN2_WINDOW_ICON`, always set by the CMake build | The window class loads icon group 1 from the exe instead of the system's generic application icon, so the taskbar and title bar show the build's icon. | The original registers the class with the system icon; the exe's own icon was only visible in Explorer. |
| 13 | `GLI/Init_Gli.c` (`GLI_fnl_InitDll`), new `GLI/GLI_linkdrv.c`; `USE_GLI_DX6`, CMake `R2_GLI_DX6` | The Direct3D 6 renderer driver (`GliDX6vf.dll/` sources) is linked into the exe. When ubi.ini names it (`GLI_DllFile=GliDX6`), `LoadLibraryA`/`GetProcAddress` in `GLI_fnl_InitDll` resolve to a table of its entry points instead of the DLL; its `DllMain` work (`GLI_vInitDllInfo`) runs at that load. Any other driver is still loaded from the DLL folder. | The renderer is part of the engine source now, and targets without DLLs (consoles) need drivers linked in. The binding code and the `GLI_DRV` interface stay as they are. |
| 14 | `GAM/pc_winmain.c` (Win32 blocks fenced `#ifndef USE_SDL`), new `GAM/sdl_main.c`; `USE_SDL`, CMake `R2_USE_SDL` | The window comes from SDL and the engine loop runs on the main thread: no engine thread, the engine events are flags, window events are pumped before every frame and while paused. Requests the engine posted to the window thread (display mode change, activation) are SDL user events served there. ERM message boxes take ERM's no-window path. Not carried over: the minimum window size, pausing on caption clicks, the power-suspend handling (one thread: the system suspends the process). | Original console structure (engine loop called directly), needed for GL contexts bound to one thread and for targets without Win32. |
| 15 | `GLI/cpu_timer.c`, `GLI/timer_sub2.c` (PC timer functions fenced `#ifndef USE_SDL`), new `TMR/sdl_timer.c`, `TMR/sdl_timer.h`; `USE_SDL` | The timer channels come from SDL: channel 0 from SDL's millisecond count, channels 1 and 2 from SDL's performance counter (channel 2 is the CPU time stamp counter on PC, its rate measured by a one-second busy wait at init). `GetTickCount` in `RND.c` and `GLI_fastload.c` counts from SDL's start instead of the system's. The system timer period is SDL's (1 ms by default). | Original console structure (the platform file gives the same timer functions); the time stamp counter is x86-only and nothing in the exe or the Direct3D 6 driver reads channel 2. |
